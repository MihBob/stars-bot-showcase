# Stars Bot

Telegram-бот для продажи Telegram Stars и Premium с автоматической выдачей.

## Возможности

- покупка звёзд по `@username` и Premium на 3/6/12 месяцев;
- приём TON с автоматическим подтверждением платежа по memo;
- автоматическая выдача через API поставщика;
- автоматический пересчёт цены от живого курса TON/RUB и закупочной цены;
- защита от двойной оплаты и от резкого изменения цены;
- админ-панель: заказы, курс, цены, статистика;
- уведомления о заказах в отдельную группу;
- ручной фолбэк: `/done <order_id>`, если автовыдача недоступна.

## Стек

- Python 3.11+
- aiogram 3
- SQLAlchemy 2 (async) + SQLite
- pytoniq (подпись TON-переводов)
- httpx

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env
# заполнить .env
python bot.py
```

Все секреты хранятся только в `.env`. Файл исключён из репозитория.

## Тесты

```bash
python -m pytest tests -q
```

Тесты офлайн: сеть, Telegram и внешние API не используются.
